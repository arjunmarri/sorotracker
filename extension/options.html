By default, all bookmarks are saved into your local JSON archive to protect against Firestore's 20,000 daily write limit. When you visit bookmarks or scan posts, the extension prompts you to manually sync in 1 single batch query whenever you are ready.
All bookmarks and history items scanned by this extension are preserved in your browser's local JSON storage (chrome.storage.local). You can export your archive as a JSON file or directly import any JSON archive into the extension at any time.
